# Deploying AquaSim

## Quick start (fresh Ubuntu 22.04+ server)

```bash
git clone https://github.com/cpatpa/AquaSim.git && cd AquaSim/v2 && bash infra/scripts/install.sh
```

That single command clones the repo and launches the guided installer, which handles everything:

- Installs Docker Engine, Compose, and system dependencies
- Prompts for your public URL, Cloudflare Tunnel token, and email config
- Generates TLS certificates, database password, JWT secret
- Builds and starts all containers
- Creates your admin account

You will have a running instance in under 10 minutes.

## What gets deployed

| Container | Purpose |
|-----------|---------|
| **app** | Node.js API server + client bundle |
| **db** | PostgreSQL 16 |
| **nginx** | TLS termination, reverse proxy, static asset caching |
| **cloudflared** | Cloudflare Tunnel (optional, for public access) |

## Requirements

- Ubuntu 22.04 or later (Debian-based distros should also work)
- 1 GB RAM minimum, 2 GB recommended
- Root or sudo access
- A domain on Cloudflare (if you want public access)

## Updating

### Manual update

From the server:

```bash
cd ~/AquaSim/v2
git pull origin main
bash deploy.sh
```

This pulls the latest code, rebuilds the containers, runs any new database migrations automatically, and restarts all services. Your `.env`, database, and Cloudflare Tunnel config are preserved.

### Automatic update via GitHub webhook

If you configured the webhook during install, pushing to `main` or `master` on GitHub triggers a rebuild automatically. No SSH required.

### What happens during an update

1. `git pull` fetches the latest code
2. `docker compose build` rebuilds the app container (cached layers make this fast)
3. `docker compose up -d` restarts only changed containers
4. The app runs database migrations on startup before accepting requests
5. PostgreSQL data persists in a Docker volume across rebuilds

Your data is safe. Containers are rebuilt from code, not replaced. The database volume (`pgdata`) is never deleted by a rebuild.

### Updating after the installer

The one-liner in Quick Start is only for first-time setup on a fresh server. If AquaSim is already installed, always use `git pull` + `deploy.sh` instead of re-running the installer.

### Rolling back

If an update breaks something:

```bash
cd ~/AquaSim/v2
git log --oneline -5          # find the last good commit
git checkout <commit-hash>    # switch to it
bash deploy.sh                # rebuild from that commit
```

To return to the latest after investigating:

```bash
git checkout main
bash deploy.sh
```

## Cloudflare Tunnel setup

The installer asks for a tunnel token. To get one:

1. Go to [Cloudflare Zero Trust](https://one.dash.cloudflare.com)
2. Navigate to **Networks > Tunnels > Create a tunnel**
3. Choose **Cloudflared** as the connector
4. Name it (e.g. `aquasim`) and copy the token

After the installer finishes, add a **Public Hostname** in Cloudflare:

| Field | Value |
|-------|-------|
| Subdomain | e.g. `aquasim` |
| Domain | your Cloudflare domain |
| Type | HTTPS |
| URL | `nginx:443` |

Under **Additional application settings > TLS**, set **No TLS Verify** to **ON** (nginx uses a self-signed cert internally).

### Adding a tunnel later

If you skipped it during install:

```bash
# Add the token to .env
echo "TUNNEL_TOKEN=eyJ..." >> .env

# Restart with the tunnel profile
docker compose --profile tunnel up -d
```

Then add the public hostname in Cloudflare as described above.

## GitHub auto-deploy webhook

The installer generates a webhook secret and prints it at the end. To set it up:

1. In your GitHub repo, go to **Settings > Webhooks > Add webhook**
2. Payload URL: `https://your-domain.com/api/webhooks/github-deploy`
3. Content type: `application/json`
4. Secret: the value from your `.env` file (`GITHUB_WEBHOOK_SECRET`)
5. Events: **Just the push event**

Pushes to `main` or `master` will trigger a `git pull && docker compose up -d --build`.

## Manual operations

```bash
# View logs
docker compose logs -f app

# Restart all services
docker compose restart

# Stop everything
docker compose --profile tunnel down

# Manual database backup
bash infra/scripts/backup.sh

# Access the database directly
docker compose exec db psql -U aquasim aquasim
```

## Environment variables

All config lives in `.env` (generated by the installer). See `.env.example` for the full list.

| Variable | Purpose |
|----------|---------|
| `APP_URL` | Public URL (used for CORS, email links, WebAuthn) |
| `DB_PASSWORD` | PostgreSQL password |
| `JWT_SECRET` | Token signing key |
| `TUNNEL_TOKEN` | Cloudflare Tunnel token (blank = LAN only) |
| `GITHUB_WEBHOOK_SECRET` | Webhook signature verification |
| `SMTP_HOST/PORT/USER/PASS/FROM` | Email for password reset |

## Backups

A daily cron job runs at 03:00, dumping PostgreSQL to `/var/backups/aquasim/` with 7-day retention. To restore:

```bash
gunzip -c /var/backups/aquasim/aquasim_20260518.sql.gz | docker compose exec -T db psql -U aquasim aquasim
```
